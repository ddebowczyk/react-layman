# 0.5.0 release notes

`0.5.0` is a breaking pre-1.0 release that requires React and React DOM 19.
It retains the controlled layout, inspection, and Tauri bridge APIs from
`0.4.0`; it adds no compatibility layer for React 18.

## Upgrade

Update the application peers and their TypeScript declarations together:

```sh
npm install react@^19 react-dom@^19
npm install --save-dev @types/react@^19 @types/react-dom@^19
```

React 18 hosts are unsupported by this release. The package test suite imports
`act` from `react`, not the removed `react-dom/test-utils` entry point.

## Validation evidence

Run these release gates from a clean checkout:

```sh
npm ci
npm test
npm run lint
npm run build:lib
npm run typecheck:consumer
npm run typecheck:tauri-example
npm run check:package
```

The TypeScript Tauri reference example is part of this gate. Before publishing,
run the native-app acceptance scenario from the `0.4.0` release notes with the
target application's React and Tauri versions recorded.
