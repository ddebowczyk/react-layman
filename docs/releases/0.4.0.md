# 0.4.0 release notes

`0.4.0` is a breaking pre-1.0 release. It replaces the v0.3 provider and
path-based public surface with a controlled view, a pure engine, and explicit
host ports. It intentionally contains no legacy API, alias, compatibility
adapter, or automatic old-snapshot migration.

## Release scope

- Use `LaymanView` and `useLaymanController` for a controlled React view.
- Use `applyLaymanCommand`, stable IDs, and `inspectLaymanState` outside React.
- Configure all tile-frame widgets through `LaymanToolbarConfig`.
- Use one `LaymanInteractionPolicy` to authorize user, host, Tauri, agent,
  toolbar, and drag commands.
- Scope themes and visual slots to a specific view.
- Connect a Tauri application with the framework-neutral workspace bridge.
- Persist only snapshot schema version `2` through application-owned storage.

Read the [migration guide](../guides/migrate-to-controlled-view.md) before
moving from `0.3.x`.

## Defect repairs

These fixes are separate from the new controlled public API:

- Reject invalid tiled and floating window addresses before a mutation.
- Reject invalid tab commands before a mutation.
- Make tab moves atomic.
- Make window moves atomic.
- Make the test command portable.
- Add repeatable component interaction tests.
- Isolate independent Layman views.
- Reject malformed persisted snapshots before they enter the engine.
- Preserve no-op and rejected state identity.

## Compatibility decision

The upstream `v0.3.0` package exported `LaymanProvider`, `Layman`, `TabData`,
`LaymanPath`, React contexts, and raw reducer-connected types. They conflict
with the stable-ID controlled boundary and are removed in `0.4.0`.

Because the package major version is zero, the breaking change increments the
minor version from `0.3.0` to `0.4.0`. It is not a patch release.

## Validation evidence

Run these release gates from a clean checkout:

```sh
npm ci
npm test
npm run lint
npm run build:lib
npm run typecheck:consumer
npm run typecheck:tauri-example
npm run check:package
```

This package repository validated with Node `v26.5.1` and npm `11.17.0`.
The TypeScript Tauri reference example is part of the gate. A native Tauri
application acceptance test is not present in this repository, so it cannot
be claimed here: run it in the consuming app's CI and record that app's Tauri
version before publishing to npm.

The native-app acceptance scenario must verify these actions:

1. Start a view with an application snapshot port and restore a workspace.
2. Open, focus, and close a module through the application module host.
3. Send a newer external workspace update and confirm it is applied once.
4. Deny a protected command through the interaction policy.
5. Inspect and steer the workspace through the live agent boundary.
6. Confirm a stale or echoed update does not replace current state.

Do not publish `0.4.0` until the application scenario passes with the target
Tauri version recorded.
